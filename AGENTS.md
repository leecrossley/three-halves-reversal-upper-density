# Contributing to this result

Ongoing work on this result belongs in [`leecrossley/prime-window-all-widths`](https://github.com/leecrossley/prime-window-all-widths/tree/main/results/three-halves-reversal-upper-density). Edit its `results/three-halves-reversal-upper-density/` directory in a branch of that repository and open the pull request there. For a distinct note on the same mathematical question, add a result directory and an entry in the [family index](https://github.com/leecrossley/prime-window-all-widths/blob/main/RESULTS.md).

Use the [research contribution guide](https://github.com/leecrossley/prime-window-all-widths/blob/main/AGENTS.md) to choose a different family when the mathematical scope calls for it. Keep the [original releases](https://github.com/leecrossley/three-halves-reversal-upper-density/releases), citation identifiers and verification records available.
